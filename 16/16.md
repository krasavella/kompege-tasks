# ВАЖНО
```python
from functools import lru_cache
```
без этой строчки ничего не будет работать, потому что лимит рекурсий дает о себе знать

## не менее важно
после функции нужно обязательно написать,
```python
for n (или ваша переменная) in range(*то, что нужно*)
```
потому что это позволяет @lru_cache держать результаты рекурсий в кэше
